# 指译 HoverLing

Linux 桌面划词翻译工具。默认使用自己划选的文字：在其他软件里选中文字，松手后在浮窗中预览，点击“翻译选中文字”再翻译。只使用所选内容，不截图、不自动取附近上下文。支持有道、DeepL、谷歌网页通道及可选 AI。

v0.5.2 将有道和谷歌的源语言改为自动识别，AI 改为多语言阅读助手，统一用简体中文返回结果。MyMemory 增加手动原文语言选择。划选、粘贴和手动输入不限制英语；服务实际支持的语种以各平台为准。旧悬停 OCR 仍仅配备英文识别模型，离线词典和本地短语库仍为英汉内容。

v0.5 增加 DeepL 官方文本翻译、独立 Key 输入、接口选择和连接测试。

v0.5.1 修正 DeepL 源语言写死为英语的问题，现在自动识别所选语言并译为简体中文；新增单请求控制、重复提交保护和限流冷却。

v0.4.2 修复 AI 回复直接显示 `**` 等 Markdown 符号的问题。浮窗和主窗口支持常见的加粗、斜体、标题、项目列表及代码显示；复制结果为可读的纯文本，代码里的字面符号会保留。原文仍按所选文字显示，不作为 Markdown 解析；较长标题可悬停查看完整原文。

## 直接启动

在本文件所在文件夹打开终端，运行：

```bash
bash launch.sh --selection
```

当前交付目录也可以直接这样运行：

```bash
bash /home/twedy/Documents/Codex/2026-11-19/neng-f/outputs/hoverling/launch.sh --selection
```

不带 `--selection` 启动时，先点“开启划词翻译”。可以将控制窗口最小化。

1. 在浏览器、PDF 阅读器或其他支持文字选择的软件中，**拖动划选你需要翻译的文字**。
2. 松开鼠标，浮窗会预览读取到的选中文字；此时不会调用翻译接口。
3. 确认范围后点**“翻译选中文字”**。一个词、一个短语或整句都可以，不会自动附加周围文字。
4. 继续划选下一段即可。浮窗中的“重新翻译所选”仍只处理同一段，不会改取附近上下文。

- **Ctrl + Alt + E**：读取当前划选，适用于没有自动出现浮窗或重复选中同一内容时。控制窗口也有“读取当前划选”按钮。
- **读不到划选时**：先按 `Ctrl + C` 复制，再按 **Ctrl + Alt + C** 或点击“翻译剪贴板”。先预览，点击翻译后才调用接口。不会自动监听或发送剪贴板内容。
- **Ctrl + Alt + Y**：暂停 / 恢复自动读取新划选；暂停时仍可主动使用上述按钮或快捷键。
- 浮窗可复制选中文字或翻译结果。移动鼠标不会立刻关闭划选浮窗；点击 × 关闭。
- 也可以在控制窗口手动输入 / 粘贴文字，点击“翻译”。手动输入和划选都不会扩展上下文。
- 默认联网开关关闭。已有有道配置继续使用；只使用离线词典时，将联网和 AI 均关闭。
- 最多接受 5000 个字符，超过会提示缩小选区，不会悄悄截断。有道处理完整选区；MyMemory 通道当前限制为 480 个 UTF-8 字节，超过会明确提示更换来源或缩小范围。

划选模式使用 Linux X11 的 PRIMARY 选区。部分软件不提供这个选区，需要使用复制备用入口；图片、视频或无法选字的界面不支持直接划词。选择范围只来自你划选或复制的文字，不使用屏幕其他区域。

旧的 OCR 悬停模式仍可在“取词与 AI 设置”中选择，但其窗口定位问题尚未解决；新划选模式不依赖那条截图 / OCR 流程。

## DeepL API

1. 先开通 **DeepL API 套餐**，再在账户的 **API Keys & Limits → Create key** 创建一个 Key。[官方 Key 获取说明](https://support.deepl.com/hc/en-us/articles/360020695820-API-key-for-DeepL-API)
2. 在工具中打开“取词与 AI 设置”，来源选择“DeepL · 官方文本翻译”。也可运行 `bash launch.sh --setup-deepl` 直接打开对应设置页。
3. 在 DeepL 区域填写 Key；它不是对话 AI，不填写在下方的 Chat Completions / 模型名称区域。接口类型先选“自动”；按 Key 的 `:fx` 后缀选择 API-Free，否则选标准接口。账户另有指定地址时，可手选下拉框对应接口。
4. 点击“测试 DeepL 连接”，会发送 `hello`，计入账户字符额度。
5. 成功后勾选“启用联网翻译”、关闭“启用 AI”，点击保存。以后只会在你点击翻译按钮时，把指定文字发送给 DeepL；不附加选区外上下文。

截至 2026-11-20，官方新用户 API Developer 提供 **100 万字符总试用额度，不按月重置**，用完需按官方页面选择其他 API 套餐。旧 API Free / API Pro 不再接受新开通；已有账户以自己的套餐为准。不要把网页 / 桌面翻译会员直接当成 API 权限。[官方套餐说明](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans)

工具使用 `POST /v2/translate` 和 `Authorization: DeepL-Auth-Key ...`，无需安装额外 SDK。标准接口为 `https://api.deepl.com`，API-Free 接口为 `https://api-free.deepl.com`。Key 只发送到选定的 DeepL 官方地址，不放入 URL 或翻译文本；保存于本机配置文件，权限 `600`，没有使用钥匙串加密。[官方认证说明](https://developers.deepl.com/docs/getting-started/auth)

DeepL 提供译文，本地短语库可补充已收录含义；它不会像通用对话模型一样逐条解释所有俚语。需要那种解释时，可另选千问等 AI。

本次接入通过模拟认证头、响应与界面测试，没有真实 DeepL Key，因此未宣称真实账户鉴权、套餐额度或翻译调用已成功。HTTP 403 会提示核对 Key / 接口类型；HTTP 456 会提示额度限制。请求失败时，已收录词可明确标记为离线备用释义。

### DeepL 提示 HTTP 429

429 表示服务端限流，不能仅凭这个状态确定是点击频率、其他客户端请求还是当前服务负载。额度限制一般返回 456，应分别处理。[官方错误处理](https://developers.deepl.com/docs/best-practices/error-handling)

- 请求处理中，重复点击同一翻译按钮或对同一内容连续回车，不会重复提交。
- 同一个 DeepL Key / 接口同时只允许一条请求；连接测试也遵守此限制。
- 收到 429 / 529 后，本程序从 30 秒开始冷却，连续限流会增加到 60、120 秒等，最高 300 秒；服务提供更长的 `Retry-After` 时以更长等待为准。
- 冷却期间再点翻译只显示剩余时间，不发送请求。冷却结束后仍需要你手动重试，不会在后台自行重复调用。
- 这些是本机保护措施，不代表 DeepL 的限流必定在对应时间内解除。持续失败时可查看 DeepL 账户及官方服务状态，或手动切回已配置的其他翻译来源。

DeepL 现在不再强制 `source_lang=EN`，让服务自动识别日语等受支持语言；只发送原选区，不补入外部上下文。

## 有道翻译（已有 Key 和 Secret）

1. 打开“取词与 AI 设置”，翻译来源选择“有道智云 · 官方文本翻译”。也可以运行 `bash launch.sh --setup-youdao` 直接打开此设置页。
2. 填入有道智云控制台的**应用 ID（App Key）**与**应用密钥（App Secret）**。不用发到聊天，也不用修改源码。
3. 点击“测试有道连接”：会发送公开示例词 `hello`，按你的有道账户额度计费；此测试不保存设置。
4. 测试成功后，勾选“启用联网翻译”，保持“启用 AI”关闭，点击“保存”。划选模式只有你点击浮窗中的翻译按钮时，才会向有道发送预览的指定文字；不附带附近上下文，不上传截图。
5. 先在控制窗口输入 `いらっしゃいませ` 等文字并翻译，确认译文来源显示“有道智云 · 官方文本翻译”。

有道使用 `from=auto` 自动识别源语言、`to=zh-CHS` 译为简体中文，并设置 `strict=true` 遵守指定的翻译方向。自动识别支持的语种范围见官方语言表；不要把“支持翻译”直接等同于“支持自动识别”。

应用需要在有道控制台绑定**文本翻译**服务，并有可用余额 / 额度。工具会说明签名错误、服务未绑定、账户欠费、IP 白名单限制及系统时间问题；错误码和配置要求见[有道官方文档](https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html)。

工具使用官方 HTTPS 接口 `https://openapi.youdao.com/api`，在本机生成 v3 SHA-256 签名。App Secret 参与本地签名，不作为请求参数发送。所填凭据保存在本机 `~/.config/hoverling/settings.json`（权限 `600`，未使用系统钥匙串加密），不会写入交付的源码包。Secret 输入框显示为掩码。

有道负责返回译文，本地短语库补充已收录的习惯用法；普通文本翻译接口不等同于任意俚语的深度语境解释。请求失败时，已收录词可显示离线释义，来源会明确标注有道调用失败；整句失败不会伪装成离线整句译文。

本次只验证了无凭据的接口网络可达性和模拟账户响应。真实 Key / Secret 尚未由用户填入，因此没有宣称真实账户鉴权或付费翻译已成功。

## 谷歌翻译

在“取词与 AI 设置”中勾选“启用联网翻译”，选择“谷歌翻译 · 网页通道”。无需填写 AI 的 API Key、地址或模型名称。点击保存后，划选和手动输入可使用谷歌译文；其网页通道当前可能要求验证，详见下文。

本版使用在制作环境实测可用的谷歌网页通道 `translate.googleapis.com/translate_a/single`。它不是 Google Cloud 的正式开发者 API，没有稳定性保证，可能因网络、限流或接口变化而不可用。不能保证永久免费可用。不会将网页通道的接口行为冒充 Google Cloud 官方承诺。

2026-11-20 的连接检查收到谷歌 `/sorry/index` 验证 / 请求限制重定向；当前在线翻译不可用，程序会显示具体原因，并对已收录词回退到离线释义。程序不会自动绕过验证。

谷歌译文负责翻译，本地短语库补充解释；不能保证对所有俚语、反讽都给出详细语境分析。需要这部分能力时，可按下一节配置 AI。

Google Cloud 的正式 API 是另一套服务，需要项目、启用 Cloud Translation 和结算、配置认证；它没有接入本版。参见[官方设置文档](https://docs.cloud.google.com/translate/docs/setup)。

### 配置千问 qwen3.7-plus

1. 在百炼控制台的 API Key 页面创建或复制一个普通模型 API Key，确认所在地域有 `qwen3.7-plus` 的调用权限。[官方 Key 获取说明](https://help.aliyun.com/zh/model-studio/get-api-key)
2. 在工具中打开“取词与 AI 设置”，勾选“启用 AI”，在展开的 AI 区域填写：

| 软件字段 | 填写内容 |
| --- | --- |
| 接口地址 | 百炼控制台对应地域的 OpenAI 兼容 Base URL |
| 模型名称 | `qwen3.7-plus` |
| API Key | 百炼的 API Key，不是有道 App Key / Secret |

北京地域的按量付费 / 试用 Key 可使用 `https://dashscope.aliyuncs.com/compatible-mode/v1`。也可使用控制台业务空间的专属地址。其他地域请使用对应地域地址，不能把不同地域的 Key 与 Base URL 混用；以[官方地址表](https://help.aliyun.com/zh/model-studio/base-url)和控制台显示为准。

3. 保存设置后，在控制窗口输入 `I'm down for the trip.` 测试，返回结果的来源应显示“AI 语境解释 · qwen3.7-plus”。有道字段可以保持原样；启用 AI 时优先使用 AI。

v0.4.1 对阿里云官方接口上的 `qwen3.7-plus` 和 `qwen4-max` 使用非思考模式，以适配短文本翻译与解释的回复预算；AI 等待时间调整为 45 秒。其他平台和仅支持思考的型号不强制修改其思考参数。[官方思考模式说明](https://help.aliyun.com/zh/model-studio/deep-thinking)

这一更新已通过 53 项逻辑测试，包括官方域名判断、千问参数和超时检查。尚未提供百炼 Key，因此未执行真实百炼账户调用。

### 其他兼容 AI 服务

谷歌翻译给出译文，离线词典给出词典义，短语库给出常见解释。需要对隐喻、反讽和新俚语进一步分析时，在“取词与 AI 设置”中：

1. 勾选“启用 AI”。
2. 填写服务商提供的 API Key、模型名称、接口地址。
3. 默认示例为 DeepSeek：地址 `https://api.deepseek.com`、模型 `deepseek-chat`；也支持兼容 Chat Completions 协议的接口（可填完整 `/chat/completions` URL）。
4. 保存后重新划选并点击翻译。AI 只会收到所选文字，不会收到选区外的画面上下文；需要更多语境时，请自行扩大划选范围。浮窗会显示自然译文及必要的词义说明。

API 调用可能收费；你需要自行提供有效 Key。交付时未配置 Key，也未验证真实 AI 账号调用。AI 的解释仍可能有误。

设置中还保留 MyMemory 作为另一种翻译来源，无需 Key，但受网络可达性与服务额度限制；制作环境未能连通此服务。此接口要求明确的语言对：选择该来源后，在“MyMemory 原文语言（手动指定）”中选择英语、日语、韩语等，再保存；默认英语，用于兼容旧配置。它不会自动判断所选语言；需要自动识别时改用有道、DeepL、谷歌或 AI。官方公布的匿名额度为每天 5000 字符，可能调整。关闭联网后，离线查询不消耗任何网络服务额度。

## 系统与依赖

本版面向 Linux **X11 / Xorg**，已在本机 Ubuntu GNOME X11 的图形环境进行窗口及截图 OCR 测试。Wayland 下不能直接使用本版全局取词；程序会提示。Ubuntu 登录时可在齿轮菜单选择“Ubuntu on Xorg”。

需要系统 Python 3.10+、PyGObject、GTK3、Tesseract 4/5 动态库。英文模型已打包，运行时无需下载。Ubuntu / Debian 若缺依赖：

```bash
# Ubuntu 24.04 / 较新 Debian
sudo apt install python3-gi gir1.2-gtk-3.0 libtesseract5

# Ubuntu 22.04 使用这个版本
sudo apt install python3-gi gir1.2-gtk-3.0 libtesseract4
```

本机已具备所需系统库。其他发行版请安装对应的 GTK3、PyGObject 和 Tesseract 包。无需 pip，不需要 root 权限运行。

## 数据与边界

- 划选模式不截图、不做 OCR。预览时不调用翻译接口；点击翻译后才发送完整指定文字，AI 也不附带选区外上下文。
- 旧悬停模式仍截取鼠标附近最多 960 × 200 的区域，在内存中 OCR；截图不落盘、不上传。这一旧模式可能使用附近文字，与新划选模式不同。
- 不会自动读取系统复制剪贴板；只有你点击对应按钮或按 Ctrl + Alt + C 才读取它。划选模式读取 PRIMARY 选区，启用时的旧选区只用于去重，不会自动翻译。
- AI API Key 及有道 App Key / App Secret 存于 `~/.config/hoverling/settings.json`，文件权限 `600`，遵循 `XDG_CONFIG_HOME`；不是系统钥匙串加密保存。翻译缓存仅存于内存，退出清除，按服务和凭据区分。
- OCR 依赖画面质量；极小字体、复杂背景、受保护画面、被遮挡内容可能无法识别。放大页面或手动输入可改善体验。
- 这里的“跨软件”指屏幕上可见且可截图的文字，并不保证所有软件和画面均可识别。文字切换但鼠标未移动时，可稍微移动指针重新取词。
- 本地短语匹配目前优先使用词库的原样表达，不能覆盖所有时态变化或被插入其他词的可分短语；接入 AI 可扩大覆盖。
